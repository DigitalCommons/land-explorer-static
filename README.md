# Land Explorer Static Site
This is the static landing page for Land Explorer. We are planning a rewrite to integrate this into the rest of the Digital Commons static site system. This codebase is only receiving minor updates for content changes as a ground-up rewrite is planned.

For the active Land Explorer codebase, see:
 - [Front End](https://github.com/DigitalCommons/land-explorer-front-end)
 - [Back End](https://github.com/DigitalCommons/land-explorer-back-end)

This is a Digital Commons Cooperative project. Please follow our 
[contributor guidelines](https://github.com/DigitalCommons#-contributing) if you 
wish to participate in building Land Explorer.
